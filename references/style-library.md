# 原创风格库

每次封面只选择一种主风格。正文配图可以使用同一风格的简化版本，保留颜色、材质和构图语法。

## 目录

1. `human-story-editorial`
2. `product-hero`
3. `concept-metaphor`
4. `warm-workbench-map`
5. `dark-system-pulse`
6. `tactile-interface-collage`
7. `high-concept-poster`
8. 内容匹配

## 1. `human-story-editorial`

适合：人物故事、文化观察、情绪观点、个人成长和 X 叙事。

视觉锚点：

1. 真实编辑摄影质感
2. 一个明确成年的原创人物
3. 场景光源真实可解释
4. 轻微颗粒、衣料褶皱、皮肤纹理和环境缺陷
5. 通过目光、空间距离和未完成动作留下叙事悬念

避免：棚拍磨皮、无关性感姿势、奢侈品广告感、多人抢焦点、名人相似度。

## 2. `product-hero`

适合：AI 工具、产品发布、项目介绍、功能升级和技术品牌。

视觉锚点：

1. 一个产品、装置或界面作为英雄主体
2. 结构清楚的工作环境或使用语境
3. 玻璃、金属、纸张、屏幕和塑料等可触摸材质
4. 一条视觉路径说明输入、变化和结果
5. 精确光影与少量高亮色

避免：漂浮图标墙、无意义霓虹、过度未来城市、密集功能列表和电商促销布局。

## 3. `concept-metaphor`

适合：行业判断、抽象观点、哲学、趋势分析和批判性文章。

视觉锚点：

1. 一个由文章核心矛盾推导出的原创隐喻
2. 大面积留白或克制背景
3. 主体之间存在清晰的尺度、方向或材质冲突
4. 颜色不超过一个主色关系加一个强调色
5. 第二眼才能发现的细节

避免：把标题修辞直接画出来、堆砌象征物、通用棋盘和灯泡、无法解释的超现实装饰。

## 4. `warm-workbench-map`

适合：教程、Skill、方法论、知识整理和工作流文章。

视觉锚点：

1. 暖白纸张或真实工作台底色
2. 手绘线条、便签、工具和路径标记
3. 卡片式信息区域和明确箭头
4. 柔和蓝、绿、紫、橙作为模块色
5. 大标题、短标签和充足留白

封面只呈现一个工作台主场景和少量流程暗示。正文配图可以展开完整结构。

避免：正文级信息全部塞进封面、儿童教材感、过多胶带装饰、无法阅读的小字。

## 5. `dark-system-pulse`

适合：自动化、代码、基础设施、安全、效率和复杂系统。

视觉锚点：

1. 深灰或近黑空间
2. 一条清楚的信号、数据流或能量路径
3. 红橙或青蓝只承担状态强调
4. 真实设备、线缆、控制面板或结构剖面
5. 高对比轮廓和克制光晕

避免：泛滥的赛博朋克城市、随机代码雨、过量光效、纯装饰网络节点和游戏海报感。

## 6. `tactile-interface-collage`

适合：内容生产、创意工具、品牌协作、媒体产品和社交传播。

视觉锚点：

1. 真实纸张、打印物、透明片、界面截图和实体道具分层
2. 清晰的前中后景关系
3. 一到两个真实界面证据点
4. 裁切、折叠、阴影和胶片颗粒形成触觉
5. 画面中心保留一个主叙事动作

避免：随机拼贴素材、未经允许的品牌标识、过多窗口、文字碎片和版权图片复刻。

## 7. `high-concept-poster`

中文名称：高级概念海报。

适合：强观点标题、品牌主张、行业判断、情绪命题、发布宣言和需要文字成为视觉核心的文章封面。

视觉锚点：

1. 用户指定的标题或视觉短句成为画面核心主文字
2. 第一眼读到主题，第二眼理解文字背后的隐喻或精神状态
3. 从内容中提炼一种最准确的视觉关系，例如连接、扩散、压迫、穿越、遮挡、托举、撕裂、照亮、分裂、融合、对抗、聚焦、回声、距离、上升或坠落
4. 图像元素只承担语义功能，保留最少且最有力的主体、空间、符号、线条、光影或抽象形态
5. 构图、配色和元素随主题重新决定，维持高级平面设计、概念海报、克制印刷质感和强记忆点
6. 主文字大、清晰、醒目，拥有合理内边距和安全裁切空间

生成时读取 `high-concept-poster.md`，使用其中的语义推导和专用提示词结构。

避免：普通插画感、简单字效、固定模板、固定配色、无意义装饰、广告页、PPT 封面、信息长图、电商海报、廉价插画、二维码、Logo、联系方式、水印、乱码和错别字。

### `cinematic-editorial-tech` 视觉模式

这是 `high-concept-poster` 的科技文章变体，适合用户希望保留高概念主标题，同时需要文章项目身份、模块语境和电影化空间叙事的封面。

视觉锚点：

1. 深色蓝黑空间、冷白入口光或单一强调色
2. 一个由文章概念推导的模块化主体，例如拼接结构、打开的缺口、可替换部件或重新组合的墙体
3. 前景、中景和后景形成明显尺度关系
4. 一个人物或单一动作作为叙事尺度证据，人物保持远景和成年身份
5. 左侧或上方建立标题层级，右侧或后方承载视觉隐喻
6. 少量真实模块标签或短解释，全部低于主标题层级

避免：无语义的服务器机房、代码雨、随机 UI、霓虹网络、漂浮图标墙、产品广告和小字堆叠。

## 内容匹配

内容匹配只用于用户没有指定风格时。用户明确要求高级概念海报、概念海报、主文字驱动封面，或提供了包含这些要求的完整提示词时，必须使用 `high-concept-poster`。例如文章主题属于 AI 产品，但用户指定概念海报，不能因为“AI 产品”标签自动改用 `product-hero`。

| 内容 | 优先推荐 |
|---|---|
| 人物、文化、情绪观点 | `human-story-editorial` |
| AI 产品、工具发布 | `product-hero` |
| 抽象观点、行业判断 | `concept-metaphor` |
| 教程、方法论、工作流 | `warm-workbench-map` |
| 自动化、安全、基础设施 | `dark-system-pulse` |
| 内容创作、媒体、品牌协作 | `tactile-interface-collage` |
| 强观点、宣言、情绪命题、高级海报 | `high-concept-poster` |
