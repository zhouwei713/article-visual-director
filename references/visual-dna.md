# 视觉基因

视觉基因用于保持账号长期识别度，同时允许每篇文章拥有新的主体和隐喻。

## 默认视觉基因

1. 一个主要视觉钩子
2. 清晰轮廓或颜色对比
3. 真实、可触摸的材质
4. 轻微的不完美和现场感
5. 一层可供读者继续解释的叙事悬念
6. 移动端缩略图仍能识别主题
7. 同系列图片共享构图语法和色彩关系

避免默认出现：

1. 通用 AI 蓝紫渐变
2. 发光大脑、机器人握手和无意义粒子
3. PPT 首页感、课程封面感和电商广告感
4. 过多标题、标签和装饰图标
5. 与文章论点无关的漂亮场景
6. 每张图都使用相同人物姿势和中心构图

## 系列一致性

采用约七成稳定、三成变化的原则。

稳定部分：

1. 一至两种主色关系
2. 线条、颗粒、纸张、金属或摄影质感
3. 标题的字重、位置和留白行为
4. 镜头高度或图形视角
5. 边框、编号和小标签系统

变化部分：

1. 文章主体
2. 场景和道具
3. 核心隐喻
4. 视觉冲突
5. 光线、天气和动作

## 可选项目配置

如果项目中存在 `.article-visual-director/profile.md`，读取它并优先采用。缺失时直接使用默认视觉基因，不阻塞工作。

建议配置字段：

```yaml
account_name: ""
preferred_platforms: [wechat, x]
signature_styles: []
primary_colors: []
accent_colors: []
texture: ""
title_policy: short-exact
people_policy: adult-original
avoid: []
```

## 参考图处理

先区分参考用途：

| 用途 | 保留内容 |
|---|---|
| `direct` | 主体身份、产品外观或必须复现的构图 |
| `style` | 线条、材质、色彩、镜头和空间关系 |
| `palette` | 主色、强调色、背景色和颜色占比 |

只在文件真实存在时记录引用路径。仅能看到对话图片时，把可见特征写入简报和提示词正文。

## 人物方向

人物封面强调明确成年、自然比例、真实皮肤和具体环境光。使用视线、姿态、遮挡、距离和道具建立情绪。保持完整遮盖和非露骨表达。原创人物排除真实名人、著名角色和品牌形象。
