# 最终版本选择

完整图文包在根目录保存 delivery.json。pages 的顺序就是交付顺序，asset_id 唯一，所有路径相对包根目录。图片修订后显式更新选择，保留未选候选。

```json
{
  "pages": [
    {
      "asset_id": "01-cover",
      "image": "images/01-cover-v2.png",
      "prompt": "prompts/01-cover-v2.md",
      "dimensions": [1080, 1440]
    },
    {
      "asset_id": "02-step",
      "image": "images/02-step.png",
      "html": "html/02-step.html",
      "dimensions": [1080, 1440]
    }
  ]
}
```

dimensions 是当前要求的像素尺寸。模型无法给出精确尺寸时记录实际尺寸及比例偏差，并说明未满足的要求，不能把期望尺寸当作实测尺寸。严格尺寸需求必须实际验证。

预览脚本不修改原图。无 delivery.json 的旧包可以生成候选审阅页，严格交付检查会失败。缺少记录、正文、标签、图片或解码失败也会阻断严格输出，已有预览不会被失败结果覆盖。Pillow 用于图片解码检查；缺失时明确报告未验证。

qa.md 分别记录契约检查、实际尺寸、逐字文字检查、事实对应、缩略图及裁切、视觉审阅。文件存在不代表这些检查通过。预览页展示检查记录，不推断审美通过。可在包根目录提供 preview-theme.css 覆盖默认主题；独立页面有不同尺寸时按实际图片展示，不裁切。

更改源文件或提示词后，旧 PNG 需要重新确认是否仍适用。当前脚本不自动证明源文件与图片的生成因果关系；在 qa.md 记录源版本与图片版本的对应关系，未确认时标记待复核。
