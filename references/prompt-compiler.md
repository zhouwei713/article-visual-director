# 提示词编译器

把文章内容、平台目标、视觉风格和画面结构融合为一份完整提示词。禁止把多个模板原样拼接，禁止保留未解析占位符。

## 约束锁定与冲突阻断

用户提供完整视觉提示词时，把它视为主协议。先保存原文，再提取以下字段到 `requirements.json`：

```json
{
  "mode": "prompt-led-cover",
  "style": "high-concept-poster",
  "aspect_ratio": "2.35:1",
  "visible_text": true,
  "text_policy": "short-exact",
  "exact_text": "",
  "allowed_text": [],
  "visual_mode": "",
  "reference_usage": "",
  "palette_policy": "topic-derived",
  "allow_textless_fallback": false
}
```

生成提示词的元数据和正文必须与这些字段一致。以下情况直接阻断：

1. 用户指定的比例被改成其他比例或跨平台主比例。
2. `visible_text: true` 时出现 `textless`、`reserved-title-zone`、“无字成图”或“画面不出现任何可见文字”。
3. `style: high-concept-poster` 时改用 `product-hero`、`dark-system-pulse`、`system-landscape` 或产品展示结构。
4. `exact_text` 没有逐字出现在文字段落中。
5. 用户要求主题决定配色时，提示词把固定色板写成不可变模板。

通用策略只能补充缺失字段。用户明确要求与通用策略冲突时，以用户要求为准。

## 文件元数据

```yaml
---
asset_id: 01
asset_type: cover
platform: x-article
aspect_ratio: 5:2
mode: prompt-led-cover
style: concept-metaphor
archetype: conceptual-tension
visible_text: true
text_policy: short-exact
exact_text: ""
output: images/01-cover.png
---
```

参考文件真实存在时才加入：

```yaml
references:
  - path: references/01-product.png
    usage: direct
```

## 平台比例

封面提示词和元数据必须写入准确比例：

1. 公众号文章封面：`2.35:1`
2. X Article 文章封面：`5:2`
3. 用户在当前任务中明确给出其他尺寸或比例时：采用用户值
4. 小红书封面和轮播卡片：`3:4`
5. 小红书方形卡片：`1:1`
6. 小红书机制图、白板图或横向对比图：`16:9`

比例必须同时出现在元数据、提示词任务句和平台适配段落中。
如果一个任务包含多个平台，分别创建对应比例的资产。除非用户明确允许，不得用一个跨平台主比例替代用户指定的单平台比例。

小红书资产元数据示例：

```yaml
---
asset_id: 01
asset_type: xiaohongshu-cover
platform: xiaohongshu
aspect_ratio: 3:4
mode: xiaohongshu-cover
render_method: imagegen
style: concept-metaphor
archetype: conflict-hook
impact_mechanism: scale-tension
page_role: cover
visual_anchor: "一个可在缩略图中识别的主要主体"
click_hook: "文章最值得点击的具体冲突"
hero_subject: "承担点击钩子的单一主体"
decisive_action: "主体正在发生的关键动作或变化"
depth_relation: "前景、中景和后景的尺度与遮挡关系"
title_subject_interlock: "标题与主体的空间关系"
safe_crop_zone: "关键元素距四边约百分之十"
thumbnail_readability: "缩小后仍能读出标题、主体和内容类型"
visible_text: true
text_policy: short-exact
exact_text: "视觉短标题"
output: images/01-cover.png
---
```

小红书每张资产在需求契约和页面计划中记录 `render_method`。轮播卡片提示词还必须说明 `page_role`、`information_answer`、`visual_anchor`、`safe_crop_zone` 和本页唯一的主要阅读任务。AI 封面提示词必须写出 `impact_mechanism`、`hero_subject`、`decisive_action`、`depth_relation`、`title_subject_interlock`、点击钩子、缩略图轮廓和信息密度。内页提示词必须写出文章证据、步骤关系或结果信号。

## 文字策略

选择一种策略并写入元数据。

| 策略 | 使用条件 |
|---|---|
| `short-exact` | 主视觉标题很短，要求模型准确生成 |
| `editorial-hierarchy` | 文章封面需要一级主标题、二级副标题和少量真实关键词 |
| `reserved-title-zone` | 用户明确允许后续人工排字，成图保留干净标题区 |
| `textless` | X 传播图、人物场景或隐喻画面无需文字 |
| `minimal-labels` | 正文信息图只使用必要短标签 |

中文标题超过十二个汉字时，只有在用户允许缩短或后续人工排字时，才提炼视觉短标题或改用 `reserved-title-zone`。如果文章封面或参考图明确需要标题、副标题和模块标签的编辑层级，可以使用 `editorial-hierarchy`。一级主文字仍需逐字列出，二级和三级文字必须来自文章或用户提供的参考内容。禁止为了降低错字风险自动删除文章标题、项目名和核心模块。

## 封面提示词结构

使用以下顺序编写自然、完整的提示词：

```text
任务：生成一张指定平台和比例的文章封面。

内容契约：
原始标题、视觉短标题、一句话主张、目标读者、第一眼主题、第二眼洞察。

画面主张：
用一句话说明核心主体、动作或冲突，以及它为什么对应文章。

构图：
主要视觉中心、前中后景、留白、阅读路径、边缘安全区和缩略图轮廓。

视觉语言：
写入所选风格的材质、光线、颜色关系、线条或摄影特征。每个风格词都要对应可见画面决定。

文字：
列出允许出现的准确文字、层级、位置和处理方式。`short-exact` 只列一级主标题。`editorial-hierarchy` 额外列出二级副标题和少量真实关键词，禁止随机小字。无字策略时明确禁止任何可见文字。

平台适配：
说明比例、裁切风险、移动端阅读和系列变体要求。

限制：
列出文章特定禁用项、通用失败模式、人物边界和参考图保留项。

输出标准：
只生成一张完整成图，不生成网格、候选拼版、解释文字或联系表。
```

### 小红书封面补充结构

小红书封面在通用封面结构后，额外写出：

```text
小红书适配：
3:4 竖幅，推荐 1080x1440。缩略图第一眼识别主题，第二眼识别点击钩子。主体、标题和辅助信息进入安全裁切区。

封面锚点：
只设置一个主要视觉锚点，说明它与文章核心观点的关系。

冲击机制：
只选择巨字透视、图文咬合、近景推进、动作瞬间、尺度冲突或单一隐喻中的一种。写清主体、决定性动作、前中后景、尺度与遮挡，以及标题和主体如何共享空间。

信息密度：
说明主标题、数字、关键词、人物、产品或结果信号的层级，禁止随机小字和装饰性标签。

移动端检查：
缩小后仍能辨认主标题、视觉主体和内容类型，顶部与底部保留安全边距。
```

封面必须让第一眼识别主题，第二眼发现冲突、洞察或隐喻。使用 `imagegen` 直接生成中文时，视觉短标题优先控制在四至八个汉字，只保留一级主标题和确有必要的少量辅助文字。完整长标题必须逐字准确且用户不允许缩短时，优先切换为 `html`。禁止把正文段落复制进画面或提示词的小字系统。

## 高级概念海报补充

选择 `high-concept-poster` 时，读取 `high-concept-poster.md` 并执行以下规则：

1. 把用户明确指定的标题或视觉短句作为一级核心主文字。用户原始提示词已经指定文字时，不得自行替换、隐藏或改成后期排字。
2. 用户只提供长文时，从原始标题提炼一条视觉短标题，并在 `brief.md` 中记录原题与短标题。文章封面需要识别项目和文章时，同时保留原始标题作为二级文字。
3. 默认采用 `short-exact`。参考图或文章编辑目标要求丰富层级时，采用 `editorial-hierarchy`。主标题逐字列出，大字号、强层级、合理内边距，并避开平台裁切区。只有用户明确批准后续人工排字时，才允许使用 `reserved-title-zone`。
4. 从内容的含义、情绪、矛盾和传播张力中选择一种主要视觉关系。
5. 每次重新推导构图、配色、元素和尺度，禁止复用固定版式。参考图可以提供版式语法，不能变成逐项复制模板。
6. 图像元素解释文字含义，排除纯装饰元素。高概念海报可以使用电影化编辑场景表达技术系统，但不得退化成通用产品渲染。
7. 输出前逐字核对一级和二级文字。乱码、错字、缺字、裁切或难以辨认均视为失败。

## 编辑型科技封面补充

当 `visual_mode` 为 `cinematic-editorial-tech` 时，提示词必须同时写出：

1. 文章项目标题和核心主张
2. 一级主标题、二级副标题和允许出现的三级关键词
3. 一个具体但抽象化的系统场景
4. 一个可解释的动作或空间关系
5. 前景、中景、后景与光线方向
6. 移动端缩略图的阅读路径

禁止把“技术主题”翻译为泛化的芯片、服务器、代码雨、霓虹网络或漂浮图标墙。若参考图包含模块化结构、人物、入口或标签，须说明它们与文章主张的对应关系。

## 正文配图提示词结构

```text
任务：为文章指定位置生成一张正文配图。

文章位置：
章节、段落和读者问题。

信息答案：
这张图必须解释的结论、数据、流程、对比或框架。

结构：
画面布局、区域数量、连接关系和阅读顺序。

真实标签：
逐字列出文章中的术语、数字、步骤名和短引用。

连续性：
沿用主封面的主色关系、材质、线条和标题行为，并根据正文阅读简化。

文字规则：
标签短、清晰、数量克制。颜色名称和色值只作为渲染指导，禁止显示在画面中。

比例与复杂度：
写明比例、移动端可读性和留白要求。

限制：
禁止装饰性场景、随机文字、无意义图标、错误数据和与段落无关的元素。
```

### 小红书轮播卡片补充结构

```text
页面职责：
本页只完成一个主要任务，写明是问题、观点、机制、证据、案例、边界、行动或互动。

信息答案：
用一句话回答本页必须让读者带走的内容。

视觉锚点：
指定一个主要主体、数字、界面、动作关系或结果信号，禁止多个焦点平分注意力。

页面连续性：
沿用整组图文的主色、字体行为、材质和编号逻辑，同时改变本页信息重点。

缩略图与裁切：
3:4 竖幅，推荐 1080x1440。重要文字和主体进入安全区，缩小后保留阅读顺序。
```

## 人物提示词补充

人物出现时写明：

1. 明确成年
2. 原创身份和自然比例
3. 具体环境光与材质
4. 视线、动作、道具和空间关系
5. 完整遮盖、非露骨
6. 排除名人、著名角色、品牌形象和明显身份漂移

## 参考图补充

`direct` 引用明确锁定主体身份、产品外观或构图。`style` 引用只提取线条、材质、光线和空间规则。`palette` 引用写出颜色关系和占比。无法直接传入参考文件时，把可见特征转写进提示词正文。

## 生成前检查

1. 所有占位符已经替换
2. 每项决定都能追溯到文章、平台、风格或参考图
3. 提示词文件已经保存
4. 输出文件名和比例明确
5. 引用路径真实存在
6. 画面文字逐字确定
7. `requirements.json` 与提示词元数据、正文不存在冲突
8. 用户要求可见文字时，提示词没有无字降级路线
