# 概念选择与页面职责

## 封面概念卡

生图前在 brief.md 简要记录文章主张、第一眼主体、第二眼关系、对应原文依据，以及缩略图保留的识别信息。用户已给完整视觉协议时只检查可执行性，不重新选题。

当方向未锁定时，比较两至三个真正不同的关系，例如人物的决定性动作、结果与代价的反差、系统入口与输出之间的转换。自动决定时自行选择，不增加确认轮次，也不默认付费生成所有候选。

用两个问题筛选：去掉标题后，画面是否仍表达这篇文章的某个具体关系？换成一篇无关文章，画面是否几乎不用改？若主体只是通用电脑、纸张或发光装置，先补文章特有的动作、对象或对照。极简文字海报可由文字与空间的关系承担语义，不强行增加说明标签。

## 多版本与系列差异

对照主体、空间关系、阅读方向、文字行为和色彩逻辑。备选封面至少在一个核心关系和一个视觉维度上形成可描述的差异，避免只换色。系列内页保持视觉基因，但随信息功能调整版式。纸张、胶片、工作台和左字右图均为可选表达，不能成为跨文章默认模板。

## 按职责分配信息

| 页面职责 | 必要信息 | 可留到其他页 |
|---|---|---|
| 封面 | 内容身份、具体钩子、视觉锚点 | 操作步骤、完整风险清单 |
| 问题或观点 | 具体情境、判断、依据 | 完整输入输出流程 |
| 步骤 | 操作对象、动作、可观察结果 | 与该步骤无关的限制 |
| 对比 | 同一比较维度、真实差异、选择依据 | 每个工具全部功能 |
| 结果或案例 | 原始证据、结果解释、必要归因 | 重复教程步骤 |
| 边界 | 触发条件、后果、应对方式 | 重述全部收益 |
| 总览或行动 | 上下游关系或可以执行的下一步 | 已讲过的细节 |

每页的事实与术语来自原文，数量由任务决定。全套教程检查信息覆盖，单页检查能否独立回答自己的问题。

## 文字与重试决策

用户原文与明确层级优先。短标题可用 short-exact；必要副标题写入 allowed_text；多级文章身份使用 editorial-hierarchy。所有预期可见文字均列入契约，并在提示词正文逐项写出。四至八字只是短标题建议，不可据此删除用户指定文字。

工具失败先查错误；视觉失败先定位具体缺陷。默认仅重试失败项一次，保留已通过项。再次失败后报告阻塞与可选路线，由用户决定继续生成或调整要求。用户新授权的修订是新一轮任务。不得静默降级成无字封面。
