# 质量门槛

生成后打开实际图片，以正常尺寸和缩略图尺寸各检查一次。对每项评分零至二分。

## 生成前契约门槛

生成前先检查 `requirements.json`、提示词元数据和提示词正文。以下任一情况直接阻断生图：

1. 用户指定比例与提示词比例不一致。
2. 用户要求可见主文字，但提示词使用 `textless`、`reserved-title-zone` 或无字降级。
3. 用户指定 `high-concept-poster`，但提示词改用产品英雄、系统景观或硬件展示结构。
4. 用户指定的核心主文字没有逐字写入文字段落。
5. 用户禁止固定配色或固定构图，但提示词把某套色板、材质或物件写成固定模板。
6. `editorial-hierarchy` 没有列出一级主标题、二级副标题和真实关键词的层级关系。
7. 参考图要求保留编辑型视觉语法，但提示词只保留口号、单一物体或无字背景。

契约检查未通过时，状态只能是“契约失败”，不得调用生图工具。

| 项目 | 0 分 | 1 分 | 2 分 |
|---|---|---|---|
| 主题识别 | 看不出主题 | 需要解释 | 第一眼明确 |
| 主要焦点 | 多个元素争抢 | 焦点略弱 | 单一明确 |
| 内容准确 | 与文章冲突 | 大致相关 | 精确对应 |
| 文章信息层级 | 缺少文章身份 | 有部分标题或标签 | 标题、主张和模块层级清楚 |
| 文章专属内容 | 换成另一篇文章仍然成立 | 有少量专属术语 | 输入、动作、输出和边界至少有三项来自原文 |
| 场景叙事 | 无动作或空间关系 | 有场景但关系弱 | 动作、空间和主张互相解释 |
| 平台裁切 | 关键内容被裁 | 边缘有风险 | 安全清楚 |
| 文字质量 | 错字或不可读 | 可读但偏弱 | 准确清晰 |
| 风格执行 | 通用模板感 | 部分执行 | 全画面一致 |
| 真实质感 | 塑料感或明显 AI 痕迹 | 基本自然 | 材质可信 |
| 系列一致性 | 像不同项目 | 有部分联系 | 统一且有变化 |
| 技术质量 | 变形、乱码或伪影 | 有轻微问题 | 干净完整 |

## 通过标准

总分至少十九分，并且没有严重失败项。以下任一情况直接失败：

1. 标题错误、缺失或严重不可读
2. 核心主体或文章主题错误
3. 人脸、手部、产品结构出现明显变形
4. 关键内容落在高风险裁切区
5. 参考人物或产品发生明显身份漂移
6. 出现未授权名人、著名角色或品牌形象
7. 出现不符合公开文章场景的露骨内容

`high-concept-poster` 还有四项直接失败条件：

1. 主文字没有成为第一视觉焦点
2. 图像元素与文字含义缺少可解释关系
3. 画面呈现固定模板、广告页、PPT 封面或廉价插画感
4. 第一眼无法读出主题，第二眼无法发现隐喻
5. 用户要求可见文字时，主文字缺失、错字、乱码或不可读
6. 画面退化为通用产品摄影、无文章语义的硬件展示或普通技术背景
7. 编辑型科技封面只剩一句口号和一个装饰物，文章标题、项目身份和核心模块全部消失
8. 多个变体只改变硬件位置、灯光或背景，没有形成独立视觉关系
9. 正文图只有通用图标和泛化步骤，无法指出文章里的具体输入、动作、输出或风险

## 修订方式

1. 判断问题属于内容、构图、风格、文字、裁切还是生成伪影。
2. 只修改相关提示词段落，保留已经通过的锚点。
3. 新建 `prompts/NN-{slug}-v2.md` 和 `images/NN-{slug}-v2.png`。
4. 重生成失败项，不重复生成已经通过的图片。
5. 再次检查真实产物并记录通过情况。

禁止通过程序化涂抹、覆盖或重绘修补生成图片中的文字。只有用户明确批准后续人工排字时，才可以生成无字版并保留标题安全区。用户要求画面出现文字时，文字缺失或错误必须重生成。

## 完成状态

使用以下三种状态：

| 状态 | 含义 |
|---|---|
| `契约失败` | 提示词与用户硬约束冲突，尚未调用生图工具 |
| `通过` | 实际图片已检查并达到门槛 |
| `部分通过` | 有图片通过，也有失败或未重试项 |
| `未验证` | 只有提示词、调用记录或预览，未检查实际图片 |

## 小红书专项检查

当平台为小红书时，额外检查以下项目：

| 项目 | 失败表现 | 通过标准 |
|---|---|---|
| 竖幅比例 | 比例错误或裁切异常 | 封面和轮播卡片默认 3:4，特殊页面明确记录其他比例 |
| 缩略图识别 | 缩小后看不出主题 | 主标题、视觉锚点和内容类型仍可辨认 |
| 点击钩子 | 只有泛化标题或装饰 | 冲突、结果、数字、前后对比或具体动作至少有一项明确 |
| 页面职责 | 每页重复同一信息 | 每页只承担一个主要任务，并有清晰阅读推进 |
| 信息密度 | 空泛大字或密集小字 | 内容具体、层级清晰、手机阅读可承受 |
| 图文对应 | 图片可替换到任何文章 | 画面包含原文输入、动作、输出或边界中的至少三项 |
| 卡片文字 | 中文错字、数字错误或乱码 | 标题、数字、步骤和标签逐字准确 |
| 系列一致性 | 每页像不同模板 | 主色、字体行为、材质和编号逻辑统一 |

小红书专项检查只判断视觉资产、图文结构、文案元数据和生成质量。它不检查账号登录、发布状态、互动数据或运营结果。
