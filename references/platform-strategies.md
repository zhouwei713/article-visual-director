# 平台策略

把比例视为平台工作基线。公众号文章封面使用 `2.35:1`，X Article 文章封面使用 `5:2`。只有用户在当前任务中明确指定其他比例时才覆盖。平台规格可能变化，当精确像素影响交付且缺少可信当前来源时，询问用户采用的发布位尺寸。

## 公众号

### 主封面

标准比例：`2.35:1`

目标：在文章列表中快速说明主题，同时保留可信、完整的编辑感。

构图规则：

1. 把主题识别信息放在中央安全区。
2. 避免把人物脸部、产品标识或关键文字贴近左右边缘。
3. 只保留一个主要焦点，辅助元素最多形成一层背景语境。
4. 标题较长时采用视觉短标题，完整标题保留在文章标题字段。
5. 技术教程优先使用主体加结构暗示，避免把整张封面做成流程图。

### 正文配图

默认比例：`16:9`。数据卡片或竖向流程可以使用 `4:3` 或用户指定比例。

配图要与段落形成信息互补。段落已经讲清楚的内容不要重复做成装饰图。

## X

先判断发布子类型。

| 子类型 | 工作预设 | 重点 |
|---|---|---|
| X Article 文章封面 | `5:2` | 宽幅叙事、中央安全区、极少文字 |
| 单图帖子或文章分享图 | `16:9` | 强轮廓、强对比、移动端第一眼识别 |
| 多图串首图 | `16:9` | 建立统一视觉语言和系列编号空间 |
| 自定义 | 用户比例 | 严格保留用户比例 |

X 视觉规则：

1. 第一眼只出现一个视觉钩子。
2. 使用清晰轮廓、颜色记忆点或尺度反差。
3. 第二眼提供故事悬念、观点冲突或可评论空间。
4. 保留真实材质、现场缺陷和轻微不完美，减少通用 AI 光泽感。
5. 多图串保持构图语法、字体行为、配色和质感一致，改变场景和信息重点。

## 小红书

小红书图文工作预设：封面和轮播卡片默认使用 `3:4`，推荐尺寸为 `1080x1440`。方形卡片可以使用 `1:1`，机制图、白板图或横向对比图可以使用 `16:9`。平台展示和裁切规则可能变化，精确发布尺寸以用户当前的发布界面或官方规范为准。

小红书封面目标是让用户在缩略图状态下快速识别主题、点击理由和内容类型。构图规则：

1. 只保留一个主要视觉锚点和一个核心点击钩子。
2. 主标题、数字、人物、产品或结果信号至少有一项在缩略图中清晰可辨。
3. 重要文字、人物脸部和产品主体放入安全裁切区，避免贴近上下左右边缘。
4. 封面信息密度要高于普通文章封面，但不能堆叠成 PPT 页面。
5. 优先选择冲突、结果、前后对比、具体数字、真实界面或明确动作作为第一眼入口。
6. 内页保持统一的主色、字体行为、材质和编号逻辑，每页只承担一个主要信息任务。

小红书正文页默认采用以下阅读推进：承诺或问题、核心判断、机制拆解、案例或证据、边界与风险、行动建议。文章较短时合并相邻任务，文章较长时拆分证据和步骤。不要为了固定页数重复标题、装饰图标或空泛金句。

标题、正文、标签和互动问题属于发布文案元数据。可以提供可配置的工作预设，例如标题不超过二十个汉字、正文不超过一千字、标签三至五个，但这些属于创作约束，不能在未核验当前平台规范时表述为永久官方限制。当前 Skill 只输出这些字段，不执行发布。

小红书视觉路由：

| 内容类型 | 优先资产 | 视觉任务 |
|---|---|---|
| 工具教程 | 真实界面、步骤卡片或机制图 | 让读者看懂输入、动作和结果 |
| 观点文章 | 冲突海报、对照图或概念隐喻 | 让读者第一眼看出立场和张力 |
| 数据内容 | 确定性数据卡、图表或对比页 | 保证数字清晰并保留来源语境 |
| 产品介绍 | 产品证据图、使用场景或前后对比 | 说明产品解决的具体问题 |
| 个人经验 | 人物叙事、物件证据或时间线 | 保留经历的具体细节和转折 |

小红书扩展仅处理视觉资产、图文结构、提示词、文案元数据和质量检查。发布自动化、登录、Cookie、定时发布和数据运营属于范围外能力。

## 跨平台改版

如果用户在原始提示词中明确指定比例，用户比例优先于平台默认。需要同时交付多个平台时，分别生成对应比例的资产，除非用户明确允许先做跨平台主图。禁止把 `5:2` 主图静默当作公众号 `2.35:1` 封面，也禁止反向处理。

从一个平台改到另一个平台时，保持以下视觉基因：

1. 核心主体
2. 主色和强调色关系
3. 材质和光线逻辑
4. 主要隐喻
5. 标题语气

重新设计以下部分：

1. 画幅和裁切
2. 阅读路径
3. 标题长度和位置
4. 辅助元素密度
5. 移动端缩略图识别
